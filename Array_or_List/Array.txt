Python lists and arrays are not exactly the same thing.
- List: A built-in Python collection that can store different data types.
- Array: Usually stores elements of the same data type, using the array module or NumPy.

1. Using a Python list []
   arr = [10, 20, 30, 40, 50]
   arr = [10, "apple", 3.14, True]
   arr = ["apple", "mango", "banana"]

2. Using the list() constructor
   
   arr = list((10, 20, 30, 40))

   arr = list((1,2,3,4))
   print(arr)
   list2 = list("pythonprogramming")
   print(list2)
   zeros = list([0] * 5)
   print(zeros)

3. Using the array module
   
   from array import array
   arr = array('i', [10, 20, 30]) # Here, 'i' means a signed integer type.
   print(arr)
